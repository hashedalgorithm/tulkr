# Security Policy

## Supported Versions

Tulkr is released as a single rolling line through the Chrome Web Store.
Only the latest published version receives security fixes.

| Version   | Supported          |
| --------- | ------------------- |
| Latest (`1.0`) | :white_check_mark: |
| < 1.0     | :x:                 |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public
GitHub issue. Instead, report it privately:

- Email: sanjaykumarcena@gmail.com
- Or use [GitHub's private vulnerability reporting](https://github.com/hashedalgorithm/tulkr/security/advisories/new)

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a minimal proof-of-concept
- Any suggested remediation, if you have one

You should receive an acknowledgment within a few days. Once the issue is
confirmed, a fix will be prepared and a new version published to the Chrome
Web Store; the reporter will be credited unless anonymity is requested.
